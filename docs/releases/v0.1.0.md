# v0.1.0 — Run what matters. Know when to stop.

The first public alpha of **risk-based-validation**, an MIT-licensed Agent Skill and local CLI for proportionate verification after a fix, feature or refactor.

## Try it

```sh
npx skills add l4vid4/risk-based-validation --skill risk-based-validation -a codex
```

The optional community installer requires Node.js 22.20+. The helper itself requires Python 3.10+ and Git, with no third-party Python runtime dependencies. A manual installer and downloadable Skill ZIP are also provided. See the [README](https://github.com/l4vid4/risk-based-validation#install).

Or clone the repository and run the isolated demo:

```sh
git clone https://github.com/l4vid4/risk-based-validation.git
cd risk-based-validation
python -m examples.demo
```

The demo executes real checks in a temporary fixture: select one local check, reuse its identical-state pass, and detect a tenant-isolation defect with fresh security checks.

## Included

- Portable Skill workflow with semantic review and explicit stopping criteria.
- Git change analysis and reviewed reverse dependency maps.
- Conservative full-inventory fallbacks and mandatory high-risk domain gates.
- Cost-based ordering, finite failure expansion and no blind retries.
- Opt-in successful-evidence reuse with content/environment/context/log checks.
- JSON reports, timeouts and explicit incomplete outcomes on budget or evidence gaps.
- Tests, executable benchmarks, raw measurements, English and Chinese documentation.

## Evidence and limits

The local tree contains 36 behavioral tests: 35 passed and one symlink-permission skip in the original Windows validation. [Public GitHub Actions](https://github.com/l4vid4/risk-based-validation/actions/runs/40826540866) then passed on Windows and Ubuntu with Python 3.10 and 3.13, including tests, demo and wheel build. The [validation record](https://github.com/l4vid4/risk-based-validation/blob/main/docs/validation.md) identifies the tested code commit; final publication edits update documentation only. Public-repository installation through the community skills CLI was also verified in an isolated temporary directory with telemetry disabled.

In the primary synthetic 12-scenario experiment, both strategies detected all 8 injected defects. Test-command time fell 25.1%, but total time **increased 39.6%**. Two larger successful scenarios reduced total time from 13.537s to 1.837s, with 0.804s additional warmup. These are single-repetition, workload-specific observations, not a production speedup guarantee.

A deliberately incorrect reviewed map causes a known miss in the negative control. Map review, meaningful check inventories and external-state identity remain trust boundaries. High-risk checks run fresh. This alpha does not replace required CI or establish that a selected pass is defect-free.
